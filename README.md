## Quick Reference

**System:** Student Digital Twin System (SDTS)  
**Purpose:** AI-powered academic intelligence platform that creates and maintains a virtual replica (digital twin) of every student, enabling predictive analytics, personalized recommendations, and real-time performance monitoring.  
**Users:** Students, Teachers, Academic Advisors, Department Administrators, System Administrators, Management  
**Core capability:** Each student has a continuously updated digital twin that mirrors their academic profile, learning behavior, skills, and career trajectory — enabling early intervention and personalized guidance.
